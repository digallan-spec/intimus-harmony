# Fonte Oficial Qafinte

Coloque aqui os arquivos licenciados da fonte **Qafinte** fornecidos no pacote oficial de marca da Clínica Umana:

- `Qafinte-Regular.woff2` (recomendado para web)
- `Qafinte-Medium.woff2` (opcional, se disponível na licença)

Em seguida, descomente o bloco `@font-face` no arquivo `src/app/globals.css` e defina `--font-qafinte: "Qafinte";`.

Enquanto o arquivo licenciado não for adicionado, a aplicação utiliza automaticamente **Cormorant Garamond** como fonte serifada substituta de desenvolvimento, preservando a estética editorial definida no Brand Book.
