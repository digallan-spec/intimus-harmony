# Materiais Visuais Oficiais — Clínica Umana

Adicione nesta pasta os arquivos oficiais fornecidos pela Clínica Umana e atualize os respectivos caminhos em `src/config/site.ts` e `src/data/content.ts`:

- `logo-umana.svg` (ou `.png` em alta resolução, versão azul-marinho para fundo claro)
- `logo-umana-claro.svg` (opcional, versão clara/dourada para o rodapé azul-marinho)
- `hero-umana.jpg` (fotografia real da clínica ou imagem oficial do procedimento)
- `jessyca-gallani.jpg` (fotografia profissional de Jessyca B. Gallani)
- `results/` — fotografias clínicas reais e autorizadas de antes e depois (ex.: `caso-01-antes.jpg`, `caso-01-depois.jpg`)

> **Importante:** nunca utilize imagens geradas por IA para representar resultados clínicos ou simulações fictícias.
